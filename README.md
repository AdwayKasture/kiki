# AI Agent Skill Builder

A tool for building, analyzing, and improving AI agent skills.

## Overview

This project is a **skill builder for AI agents**. It provides an interface to inspect agent sessions, discover reusable patterns, and turn those patterns into testable, reusable skills.

## Planned Features

- **Session Comparison**  
  Compare two agent sessions to identify what is common between them and generate evaluations from the shared behavior.

- **Tool Call Extraction**  
  Extract common tool calls from sessions and turn them into reusable scripts.

- **Harness-Agnostic Skills**  
  Build agent skills that work across different harnesses and evaluation frameworks.

## Tech Stack

Built with **React**, **TypeScript**, and **Vite**.

## Development

Run the local dev server with:

```bash
bun run dev
```
